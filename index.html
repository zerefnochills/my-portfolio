about me

Hi! I’m a passionate developer who bridges the gap between clean code architecture and delightful visual design. I believe software should not only be reliable and fast, but feel humane and enjoyable to use.

When solving problems, I always draft ideas on a notebook first—mapping state flows, database relations, and user journeys with ink before opening an editor. This tactile approach keeps my code intentional and well-structured.
